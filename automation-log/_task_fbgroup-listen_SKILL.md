## 🔴 ด่าน 0.5 — แท็บต้องอยู่หน้าจอ ไม่งั้นฟีดไม่โหลด (พบจริง 20 ก.ค. 19:10)
Facebook หยุด render ฟีดเมื่อแท็บอยู่เบื้องหลัง (document.visibilityState = hidden) → เลื่อนเท่าไรก็ได้โพสต์เดียว → จะสรุปผิดว่า "กลุ่มไม่มีโพสต์ที่ตอบได้"

ตรวจหลังเปิดกลุ่มและเลื่อน 3-4 ครั้งแล้ว:
- `document.body.innerText.length` < 2000 หรือ `document.visibilityState` = 'hidden' และนับ [role=article] ได้ <= 1
- เข้าเงื่อนไขนี้ = **รายงาน "แท็บอยู่เบื้องหลัง อ่านฟีดไม่ได้ ต้องให้เจ้าของคลิกแท็บขึ้นหน้าจอ" แล้วหยุด**
- **ห้ามสรุปว่ากลุ่มไม่มีโพสต์ที่ตอบได้เด็ดขาด** (สองรอบที่ผ่านมาพลาดเพราะสรุปจากข้อมูลที่โหลดไม่ครบ)

ห้ามใช้ SendKeys/คีย์ลัดของ Chrome (Ctrl+9, Ctrl+Shift+A) เพื่อสลับแท็บ — ลองแล้ว 20 ก.ค. ได้ผลผิดและเปิดหน้า Chrome Help ค้างไว้ในเบราว์เซอร์เจ้าของ
## ขั้นตอน
1. ด่าน 0 (identity) ให้ผ่านก่อนเสมอ
2. **เลือกกลุ่มวันนี้:** grep `automation-log/post-ledger.jsonl` หา `channel=fb-group` → ดู field `group` → **เลือกกลุ่มที่ยังไม่เคยคอมเมนต์ก่อนเสมอ** (หมุนเวียนให้ครบ 7 กลุ่มก่อนวนซ้ำ)
3. เปิดกลุ่มนั้นด้วย URL ตรง → อ่านโพสต์ล่าสุด ~15 โพสต์ → หาโพสต์ที่ผ่านครบ 4 ข้อ:
   (a) โพสต์ภายใน ~2 วัน (b) ตรงหัวข้อเรา (หนี้/บัตร/ออมเงิน/บูโร/สินเชื่อ) (c) เจ้าของโพสต์ขอความช่วยเหลือจริง (d) ยังไม่มีคำตอบดีๆ ครอบไว้
4. ร่างคำตอบไทย value-first เจาะเคสนั้นจริง — **ไร้ลิงก์ ไร้แบรนด์ ไร้ราคา ไร้ตัวเลขดอกเบี้ย ไร้การันตี** · เตือนภัยมิจฉาชีพเมื่อเข้าเรื่อง · ปิดท้ายชวนคุยได้ ห้ามขาย
   ⚠️ กลุ่ม "ปลดหนี้ ฉบับมนุษย์เงินเดือน" มีกฎ **ห้ามโพสต์ขายสินค้า/บริการ เจอลบทันที** — เข้มเป็นพิเศษ
5. **ห้ามโพสต์/คอมเมนต์เองเด็ดขาด** — ส่งให้เจ้าของเคาะในแชต (URL โพสต์ + เหตุผล 1 บรรทัด + ร่างพร้อมวาง) ร่างได้ ≤3/วัน
6. เพดานหลังอนุมัติ: **ตอบจริง ≤1 กลุ่ม/วัน** ห้ามยิงหลายกลุ่มวันเดียวกัน (FB จับ pattern spam)
7. เช็กสัญญาณ mod: คอมเมนต์เก่าของเราถูกลบ / โดนเตือน / ถูกเตะ = **หยุดกลุ่มนั้นถาวร** + รายงานดังทันที
8. เขียนผลลง `automation-log/FBGROUP-LISTEN_<YYYYMMDD>.md` · หลังเจ้าของอนุมัติและโพสต์แล้วค่อย append ledger `channel=fb-group` พร้อม field `group`
