## ⏰ 1 · GA4: ลงทะเบียน custom dimension — **ต้องทำก่อนข้อมูลเริ่มสะสม**

**ทำไมด่วน:** GA4 **ไม่ย้อนหลัง** · พารามิเตอร์ที่ไม่ได้ลงทะเบียนไว้ จะหายไปตลอดกาล
เราเพิ่งติดปุ่มซื้อ 3 จุดบน `/debt-letter-kit` (บน / กลาง / ล่าง) และจะอ่านผลวันที่ 8 ส.ค.
**ถ้าไม่ทำวันนี้ วันที่ 8 เราจะรู้แค่ "มีคนกด" แต่ไม่รู้ว่ากดปุ่มไหน** — ซึ่งคือสิ่งที่จะบอกว่าควรย้ายปุ่มหรือไม่

**ทำ (~2 นาที):**
1. เปิด GA4 → property **ngernduangold web** (`G-17PPE0M1B8`)
2. เมนูซ้ายล่าง **Admin** (รูปเฟือง) → คอลัมน์ Property → **Custom definitions**
3. **Create custom dimension** → กรอก:
   - Dimension name: `position` · Scope: **Event** · Event parameter: `position`
4. ทำซ้ำอีกครั้งสำหรับ:
   - Dimension name: `product` · Scope: **Event** · Event parameter: `product`
5. Save

**ถ้าข้ามข้อนี้:** ยังตัดสินตามตาราง 8 ส.ค. ได้ (ตารางใช้แค่ 0 กับ >0) แต่จะเสียข้อมูลว่าปุ่มไหนทำงาน และไม่มีทางได้คืน

## 3 · GA4: กรอง internal traffic (ทำเมื่อสะดวก)

**ทำไม:** 79% ของ "ทราฟฟิก" ที่วัดได้เป็นหุ่นยนต์ของเราเอง — `direct` 166 session ลงหน้าแรก 162 view โดยไม่มี engagement เลย
ผมแก้ที่ต้นทางไปแล้ว 2 จุด (uptime monitor เลิกเปิดเบราว์เซอร์ตอนเว็บปกติ · ลดความถี่ครึ่งหนึ่ง) แต่การกรองที่ GA4 จะปิดปัญหาถาวรกว่า

**ทำ:** GA4 → Admin → **Data Streams** → เลือก stream → **Configure tag settings** → **Show more** → **Define internal traffic**
เพิ่มกฎ: `traffic_type = internal` เมื่อ query parameter มี `uptime` หรือ `ga_internal`
แล้วไปที่ **Data Settings → Data Filters** → เปิด filter "Internal Traffic" เป็น **Active**

**ถ้าข้าม:** ตัวเลข sessions จะยังปนอยู่บ้าง แต่น้อยลงมากแล้วจากที่แก้ไป
