```
อ่านแล้วเข้าใจสถานการณ์ครับ มีบ้านผ่อนอยู่ ติดบัตรด้วย บูโรเริ่มเสียแล้ว รายได้ประจำ 17,000 คือเงินไม่พอหมุนทุกทางพร้อมกัน ไม่ใช่เรื่องขี้เกียจจ่าย ขอแยกให้เห็นเป็นข้อ ๆ นะครับ

หนึ่ง จัดลำดับก่อนว่าอะไรห้ามพลาด บ้านเป็นหนี้ที่มีหลักประกัน ถ้าขาดส่งจะเดินไปทางบังคับจำนองและเสียบ้าน ส่วนบัตรเป็นหนี้ที่ไม่มีหลักประกัน เจรจาได้ยืดหยุ่นกว่ามาก ถ้าเงินมีจำกัดจริง ๆ ให้ประคองงวดบ้านไว้ก่อน แล้วไปเจรจาฝั่งบัตร

สอง ฝั่งบ้าน ถ้ารู้ตัวว่าเดือนหน้าเริ่มตึง ให้ยื่นขอปรับโครงสร้างกับธนาคารเจ้าของสินเชื่อตั้งแต่ยังไม่ค้าง ขอลดค่างวด ขยายระยะเวลา หรือพักชำระเงินต้นชั่วคราว เงื่อนไขที่ได้ตอนยังไม่ค้าง ดีกว่าตอนค้างแล้วเกือบทุกกรณี

สาม ฝั่งบัตรที่บูโรเสียไปแล้ว มีช่องทางทางการให้ลองเช็กสิทธิ์ คือคลินิกแก้หนี้ โทร 1443 ซึ่งทำมาสำหรับหนี้บัตรและสินเชื่อส่วนบุคคลที่ไม่มีหลักประกันและกลายเป็นหนี้เสีย รวมเจ้าหนี้หลายรายมาผ่อนที่เดียว งวดยาวขึ้น ต่อเดือนเบาลง ต้องให้เขาตรวจว่าเข้าเกณฑ์ไหมนะครับ ไม่ใช่ทุกเคสจะเข้าได้ ถ้าไม่แน่ใจว่าควรเริ่มตรงไหน โทรถามศูนย์คุ้มครองผู้ใช้บริการทางการเงิน ธปท. 1213 ได้ ฟรีทั้งสองเบอร์

สี่ ก่อนโทรหาเจ้าหนี้ทุกครั้ง เตรียมสามตัวเลขนี้ให้พร้อม รายได้ที่เข้าจริงต่อเดือน ค่าใช้จ่ายที่ตัดไม่ได้ และยอดที่จ่ายไหวจริงต่อเดือน เพราะเจ้าหนี้จะถามข้อสุดท้ายเสมอ ถ้าตอบไม่ได้เรื่องจะจบแค่ให้กลับไปคิดมาใหม่แล้วเสียเวลาอีกรอบ และทุกครั้งที่คุยให้ขอเลขรับเรื่องกับชื่อเจ้าหน้าที่ไว้ด้วย จดวันเวลาทุกครั้ง

ห้า กับดักที่อยากเตือนตรง ๆ ในโพสต์แบบนี้จะมีคนเสนอว่าปิดหนี้ให้ก่อนยื่นกู้ ฟรี มีเงินทอน ต้องเข้าใจว่าไม่มีใครเอาเงินตัวเองมาปิดหนี้ให้เราฟรีจริง ต้นทุนตรงนั้นถูกบวกกลับเข้าไปในยอดที่เราต้องผ่อนอยู่ดี และถ้าเงินทอนมาจากการทำราคาซื้อขายให้สูงกว่าราคาจริง นั่นคือการให้ข้อมูลที่ไม่ตรงความจริงกับธนาคาร คนที่ชื่ออยู่ในสัญญาคือคนที่รับความเสี่ยงเต็ม ๆ คนเดียว ทั้งเรื่องถูกเรียกวงเงินคืน เรื่องคดี และประวัติที่จะติดตัวไปอีกนาน ที่สำคัญคือตอนนี้ปัญหาคือหนี้ที่มีอยู่ ไม่ใช่ว่ายังมีบ้านไม่พอ การก่อหนี้ก้อนใหม่ที่ใหญ่กว่าเดิมจึงไม่ได้แก้ที่ต้นเหตุ
```

## ขั้นตอนหลังเจ้าของเคาะ
1. เปิด URL ของร่างที่เลือก → ตรวจว่าช่องคอมเมนต์ขึ้นว่า **"แสดงความคิดเห็นในชื่อ เงินเดือนสมองทอง"** ก่อนวาง (ถ้าขึ้นชื่อ Kunanon = หยุด สลับตัวตนก่อน)
2. วางคอมเมนต์ **1 โพสต์เท่านั้น** วันนี้
3. บันทึก ledger: `channel=fb-group` · `group=ปิดหนี้ อยากมีบ้าน บูโร` · `post=<url>` · `policy=no-link-no-brand-no-price`
4. ถ้ามีคนทักเข้ามา → ก็อปโจทย์เคส (สถานะ / ประเภทหนี้ / ค่างวดที่ไหว **ห้ามมีชื่อ เบอร์ เลขบัญชี**) มาวางในแชต แล้ว AI ร่างประโยคเปิดเจรจา + สคริปต์โทรให้ทันที (~3 นาที/เคส)

## บันทึกเทคนิค (สำหรับรอบถัดไป)

### ⚠️ แท็บอยู่เบื้องหลัง — ฟีดกลุ่มโหลดได้แค่ 1 โพสต์ (ยืนยันซ้ำวันนี้)
`document.visibilityState = hidden` · spoof visibility + wheel scroll ปลดล็อกได้แค่บางส่วน — วัดจริง: scrollHeight ค้างที่ ~1,900px, `innerText.length` 867–1,097 (ต่ำกว่าเกณฑ์ 2,000), เลื่อน 16 รอบเพิ่มความสูงแค่ ~8px/รอบ · ทดสอบ m.facebook.com แล้วถูก redirect กลับ www · fetch HTML ตรง ๆ ไม่มีเนื้อฟีด (โหลดผ่าน GraphQL แยก)

### ✅ ทางออกที่ใช้ได้จริง — ใช้ "ค้นหาในกลุ่ม" แทนการเลื่อนฟีด
`facebook.com/groups/<id>/search/?q=<คีย์เวิร์ด>` **เรนเดอร์ผลลัพธ์ 5–6 โพสต์พร้อมข้อความเต็ม + URL + วันที่ ในครั้งเดียว แม้แท็บอยู่เบื้องหลัง**
โบนัส: ผลค้นหาบอก **สถานะคอมเมนต์** ให้ในตัว — ถ้าเห็น "แสดงความคิดเห็นในชื่อ เงินเดือนสมองทอง" = เปิด · ถ้าเห็น "ได้มีการปิดการแสดงความคิดเห็น" = ปิด → คัดโพสต์ที่คอมเมนต์ปิดออกได้ตั้งแต่ก่อนเปิดอ่าน (แก้บทเรียน 20 ก.ค. ที่เสียเวลาร่างให้โพสต์ที่ปิดคอมเมนต์)

**คีย์เวิร์ดที่ใช้ได้ผลวันนี้:** `จ่ายไม่ไหว` · `ปรับโครงสร้างหนี้` · `ค้างบัตร` · `หนี้บัตร`
**คีย์เวิร์ดที่ควรลองรอบหน้า:** `โดนทวง` · `หมายศาล` · `อายัดเงินเดือน` · `โทรหาแบงก์`
