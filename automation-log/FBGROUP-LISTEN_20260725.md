## 🔧 บทเรียนเทคนิครอบนี้
1. สูตรปลดล็อก background-tab ของ 24 ก.ค. **ใช้ได้ซ้ำ** (spoof `visibilityState` + wheel scroll จริงผ่าน computer tool) → อ่านฟีดได้ 19–23 โพสต์/กลุ่ม
2. **ข้อจำกัดใหม่ที่เจอ:** ช่องพิมพ์คอมเมนต์ (composer) บางโพสต์ไม่ยอม hydrate เมื่อแท็บอยู่เบื้องหลัง → ทำให้ "ยืนยันว่าคอมเมนต์เปิด" ไม่ได้ 100% · **ห้ามสรุปว่าปิด** ถ้าไม่เจอข้อความ "ปิดการแสดงความคิดเห็น"
3. `Page.captureScreenshot` timeout 1 ครั้ง (renderer ถูก throttle) — แก้ด้วยการ reload แล้วเลื่อนใหม่
4. ดึง URL โพสต์ต้อง **ตัด query string ออกก่อน** ไม่งั้นโดนบล็อก (ใช้ regex ดึงเฉพาะเลข post id แล้วประกอบ URL เอง)

1. เลือก **1 ร่าง** ที่จะวางจริงวันนี้ (เพดาน ≤1 กลุ่ม/วัน) — แนะนำ **Draft #1** เพราะยืนยันแล้วว่าคอมเมนต์เปิด
2. ถ้าจะใช้ Draft #2 ให้เปิดโพสต์บนหน้าจอจริงเช็กว่าพิมพ์คอมเมนต์ได้ก่อน
3. พิจารณาว่าจะตาม **คำขอเข้ากลุ่ม "ปลดหนี้ ฉบับมนุษย์เงินเดือน"** ที่ค้างมา 6 วันต่อ หรือปล่อยไว้
