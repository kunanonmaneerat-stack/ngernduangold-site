## 2) ของใหม่ที่เราไม่เคยคิด (เอาไปใช้ได้เลย)

### จาก ChatGPT
1. **LINE deep-link พร้อมข้อความกรอกไว้แล้ว** — แก้ปัญหา "แอดแล้วไม่รู้จะพิมพ์อะไร" ตรงจุด (LINE รองรับ `?text=` ใน URL เปิดแชท OA) → ลดแรงเสียดทานขั้นที่รั่วที่สุด **โดยไม่ต้องเขียนโค้ดใหม่**
2. **"แปลข้อความทวงหนี้เป็นภาษาคน"** — ให้ผู้ใช้ส่งภาพ/ข้อความที่ปิดข้อมูลส่วนตัวแล้ว → ตอบว่า เขาขออะไร / รีบแค่ไหน / ถามกลับ 3 ข้อ / ประโยคตอบ = lead magnet ที่เกิดตอนเจ็บสุด และต่อยอดขายชุดจดหมายตรงๆ
3. **หน้า intent แยกตามเจ้าหนี้** — "ค้าง KTC 2 งวด" / "AEON จ่ายขั้นต่ำไม่ไหว" / "First Choice ปิดบัญชีลดยอด" = long-tail ที่ใกล้ซื้อมากกว่า "วิธีปลดหนี้"
4. **แยก intent ของ affiliate ออกจากหน้าคนเป็นหนี้** — หน้า "ช่วยคนเป็นหนี้" ห้ามมี CTA สมัครบัตร/สินเชื่อด้านบน (เราทำผิดอยู่: บทความดอกเบี้ยบัตรมี CTA สมัครบัตรเครดิตด้านบน ทั้งที่ผู้อ่านกำลังทุกข์จากหนี้บัตร)
5. **ลด index-nudge รายวัน** — Google ระบุเองว่า Request Indexing ไม่รับประกัน และเว็บหลายหน้าควรพึ่ง sitemap + `<lastmod>` → ที่เราทำรายวันคือเสียเวลาเปล่า
6. **รับประกันแบบมีขอบเขต** — "ถ้าชุดที่ได้ไม่มีฉบับตรงสถานะหนี้ แก้ให้ฟรี 1 รอบ" (ไม่รับรองว่าเจ้าหนี้อนุมัติ = ปลอดภัย compliance)

### จาก Gemini
7. **Payday / หวยออก timing** — 25–31 = วันจ่ายหนี้ที่เจ็บสุด · 1 กับ 16 = วันหวยออก ความหวังพัง → ปล่อยคอนเทนต์จังหวะนี้ conv สูงสุด *(ChatGPT ก็เสนอ Payday Triage 25–31 เหมือนกัน = ยืนยันซ้ำ)*
8. **"กล่องระบายเรื่องหนี้" แบบไม่ระบุตัวตน** — Google Form ให้คนบ่น → เอาเคสพีคมาทำคอนเทนต์ "รีวิวหนี้ 5 แสนจากบัตร 4 ใบ อายุ 27" (คนไทยอายเปิดเผยหนี้ตัวเอง แต่ชอบดูของคนอื่น)
