## 5. ข้อมูลประกอบที่เจ้าของขอให้พูดตรงๆ

**วิดีโอกินแรงผลิตมากที่สุดในระบบ แต่ให้ผลน้อยที่สุด:**

```
Threads   22 ชิ้น →  0 session   (0.0/ชิ้น)
Pinterest  9 ชิ้น →  0 session   (0.0/ชิ้น)
TikTok     1 ชิ้น →  0 session   (0.0/ชิ้น)
────────────────────────────────────────────
Pantip     3 ชิ้น → 14 session · 4 conv  (4.7/ชิ้น · conv 1.33/ชิ้น)
```

Pantip ทำแค่ 3 คอมเมนต์ ได้ conversion **4 จาก 7 ของทั้งเว็บ**
ถ้าเวลาเจ้าของมีจำกัด การเลือก (ค) แล้วเอา ~12 อัปโหลด/สัปดาห์ที่ประหยัดได้ไปทำ Pantip/FB Groups **น่าจะให้ผลตอบแทนสูงกว่ามาก**

**แต่นี่คือข้อมูล ไม่ใช่คำตัดสิน** — ข้อโต้แย้งที่ควรชั่งด้วย:
- Pantip **ติดเพดานนโยบายอยู่** (≤3/สัปดาห์ post-final-warning) → เทเวลาเข้าไปก็ขยายไม่ได้เกินเพดาน เวลาที่ประหยัดต้องไปลง **FB Groups** เป็นหลัก
- batch3 เป็น batch แรกที่มีเสียงพูดจริง = **ยังไม่เคยรู้ผลของสูตรใหม่เลย** การตัดก่อนอ่านผลคือตัดการทดลองทิ้ง
- North Star = ยอดขาย 199฿ ผ่าน LINE ซึ่งตอนนี้ **= 0** ทุกช่อง → ไม่มีช่องไหนพิสูจน์ตัวเองบนเกณฑ์จริงเลย
