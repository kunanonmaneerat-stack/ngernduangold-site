## 1. ใส่ `tools/test_sweep.py` เข้ารอบ cron รายสัปดาห์ — ไม่งั้นมันคือเครื่องมือที่ไม่มีใครรัน

รีโปมีเทสต์ 116 ชุด cron รัน 1 ชุด (`run_daily.cmd:249`) · sweep เพิ่งพิสูจน์วันนี้ว่าจับของจริงได้ (เทสต์ 2 ชุดเขียนทับปฏิทินจริง, interpreter ผิด, 8 ชุดที่แดงเพราะ runner ไม่ใช่เพราะโค้ด)
Cowork ไม่ใส่เองเพราะ `pipeline/task_run_receipt.py:186-191` ล็อกรายชื่อขั้นของ weekly ไว้ และมีเทสต์คุม — เพิ่มขั้นโดยไม่แก้สัญญา receipt = RUNNER_FAILED ทั้งรอบ

**ขอ:** เพิ่มเป็นขั้น `:graded` ท้ายรอบ `run_weekly.cmd` (หลัง improvement_loop ก่อน close_receipt) พร้อม:
- สัญญาใหม่ใน receipt เช่น `test-sweep-v1`: `0 → PASS`, `1 → REVIEW_REQUIRED` (มีชุดที่ขยับ), `2 → BLOCKED` (สแกนไม่ได้) · **1 ต้องไม่ abort** — สัญญาณ "ขยับ" มีไว้ให้คนอ่าน ไม่ใช่ให้หยุดการวัดผล
- อัปเดต `test_task_run_receipt.py` และเทสต์อื่นที่ล็อกรายชื่อขั้น
- timeout ต่อรอบ ≤ 15 นาที (วันนี้ทั้งชุดใช้ ~7 นาที) · sweep เลือก interpreter เองแล้ว ไม่ต้องส่ง `%PY%` ให้มัน แต่**ตัวมันเอง**ต้องถูกรันด้วย `%PY%`
- **ห้าม**ใส่ใน daily — 7 นาทีทุกเช้าไม่คุ้ม และ daily ต้องจบก่อนสล็อตโพสต์แรก

## 2. GA4 internal traffic: เลิกยึด IP — ออกแบบให้ Cowork ก่อน ยังไม่ต้องทำ

หลักฐาน (`FINDINGS-CRON-LAYER_20260910.md` §3): trust = UNTRUSTED ตั้งแต่ 6 ก.ย. เพราะ ISP หมุน IP ออกนอก `/32` ที่ตั้งไว้ · `rotation_history` ของคุณเองบันทึกว่าหมุนข้าม /24 ใน 6 วัน · สัญญา attestation เริ่ม 28 วันใหม่ทุกครั้งที่ CIDR เปลี่ยน ⇒ **หน้าต่างสะอาดไม่มีวันครบโดยโครงสร้าง**

**คำถามที่ขอให้ตอบ (ออกแบบ ไม่ใช่ลงมือ):**
1. ถ้าย้ายไปตั้ง `traffic_type=internal` ที่ gtag ฝั่งเบราว์เซอร์ของเจ้าของ (flag ใน localStorage เปิดครั้งเดียว) และให้ GA4 data filter กรองที่ค่านั้น — **trust evaluator จะพิสูจน์อะไรได้จากเครื่องนี้** ในเมื่อสิ่งที่ต้องยืนยันคือ "เบราว์เซอร์ที่เจ้าของใช้ติด flag" ไม่ใช่ "IP อยู่ใน CIDR" · ถ้าพิสูจน์ไม่ได้ ให้บอกว่าไม่ได้ และเสนอสิ่งที่พิสูจน์ได้จริงแทน
2. traffic ที่เกิดจากเครื่องนี้เองที่**ไม่ผ่านเบราว์เซอร์** (uptime_check = urllib, CC ยืนยันแล้วว่าไม่สร้าง session GA4) ยังต้องกรองไหม — ตอบจากโค้ด ไม่ใช่จากความเชื่อ
3. สัญญา `GA4-COVERAGE-ATTESTATION-CONTRACT.md` ต้องเปลี่ยนตรงไหน และหน้าต่าง 28 วันควรเริ่มนับใหม่จากอะไรแทน CIDR change
4. ระหว่างยังไม่ย้าย: ขั้นตอนสั้นที่สุดให้เจ้าของเพิ่ม /32 ปัจจุบันใน GA4 Admin แล้ว Cowork บันทึก observation ตามสัญญา — เขียนเป็น checklist 5 บรรทัด **ห้ามมีที่อยู่เครือข่ายในเอกสาร**
