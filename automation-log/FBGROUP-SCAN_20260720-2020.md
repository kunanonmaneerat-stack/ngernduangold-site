# สแกน FB Groups หาโพสต์คอมเมนต์เปิด (20 ก.ค. 20:20 · แท็บ visible จริง)

หลังโพสต์คลิป Threads สำเร็จ เจ้าของสั่งหาโพสต์กลุ่มเพิ่มที่คอมเมนต์เปิด — สแกน 4 กลุ่มด้วย visibilityState=visible

| กลุ่ม | โพสต์เด่นที่เจอ | ตัดสิน |
|---|---|---|
| ปรึกษาหนี้บัตรเครดิตฯ | CozyPear (สินเชื่อรวมหนี้ ข้อมูลครบ) | ❌ ปิดคอมเมนต์ |
| ปรึกษาหนี้บัตรเครดิตฯ | ThrillingGuava (ปล่อยหนี้เสียเข้า SAM) | ❌ ปิดคอมเมนต์ + หัวข้อเชียร์ผิดนัดชำระ (off-brand) |
| ปิดหนี้ อยากมีบ้าน บูโร | Phatrin/จักร์พรรณ/Suleephan | ❌ ทั้งหมดเป็นโพสต์นายหน้า/รับปิดหนี้ ไม่ใช่คนถามจริง |
| วิถีออมเงินมนุษย์เงินเดือน | Thimaphorn/Jeab/ธันยพร | ⚪ โพสต์ให้กำลังใจ/แชร์ยอดออม ไม่ใช่คำถามขอคำแนะนำ |

## ข้อค้นพบเชิงยุทธศาสตร์ (สำคัญต่อ gate 27 ก.ค.)
กลุ่มหนี้บน FB คุณภาพต่ำกว่าที่ shortlist คาด:
1. **นายหน้า/รับปิดหนี้ครองฟีด** — โพสต์ส่วนใหญ่คือโฆษณาบริการ ไม่ใช่คนขอความช่วยเหลือ
2. **คำถามจริงมักถูกปิดคอมเมนต์** — แอดมินปิดเพื่อกันมิจ/นายหน้ามาตอบ (เราเห็นคอมเมนต์มิจ "ปิดหนี้ให้ฟรี" ในโพสต์ CozyPear ก่อนถูกปิด)
3. กลุ่มออมเงินคุณภาพดีกว่า แต่เป็นโพสต์โซเชียล/ให้กำลังใจ แทบไม่มี Q&A

→ ตามกฎเราเอง "ไม่มีโพสต์ผ่านเกณฑ์ = หยุด ห้ามฝืนร่างคุณภาพต่ำ" → **คืนนี้ไม่คอมเมนต์ ถูกต้องแล้ว**
→ ข้อเสนอสำหรับ gate 27 ก.ค.: FB Groups อาจไม่ใช่ช่อง borrowed-reach ที่คุ้มเท่า Pantip · ควรลดน้ำหนัก เพิ่มเวลาให้ Pantip (ที่พิสูจน์แล้วว่าพาคนใหม่มาได้)

## จุดที่แก้ให้ fbgroup-listen แล้ว (commit ก่อนหน้า)
- ด่าน 0: identity ต้องเป็นเพจเงินเดือนสมองทอง
- ด่าน 0.5: ต้อง visibilityState=visible (Ctrl+9 ให้แท็บ active) ไม่งั้นอ่านฟีดไม่ครบ
- เช็ก "ปิดการแสดงความคิดเห็น" ก่อนร่างทุกครั้ง
