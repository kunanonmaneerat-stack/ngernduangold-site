## 1. สิ่งที่ตรวจสดวันนี้

### 1.1 token — ยังเป็นสภาพเดิมทุกประการ

```
secrets/yt_token.json
  scopes : ["https://www.googleapis.com/auth/youtube.upload"]
  refresh: สำเร็จ (token ยังใช้ได้ ไม่ได้หมดอายุ)
  scope ที่ Google คืนกลับหลัง refresh: youtube.upload  ← ไม่มี readonly
```

เรียก Data API จริงวันนี้ (`videos?part=statistics` · 3 คลิป):

```
HTTP 403  ACCESS_TOKEN_SCOPE_INSUFFICIENT
"Request had insufficient authentication scopes."
method: youtube.api.v3.V3DataVideoService.List
```

> **จุดที่ต้องระวัง:** token *refresh ผ่าน* — ดูเผินๆ เหมือนสุขภาพดี
> ไฟล์ถูกแตะล่าสุด 9 ส.ค. 08:12 ซึ่งคือการ refresh อัตโนมัติ **ไม่ใช่การ re-auth**
> re-auth ต้องผ่านหน้าจอยินยอมของ Google ใหม่ และ `scopes` ในไฟล์จะเปลี่ยน — มันไม่เปลี่ยน

**ดังนั้นรอบหน้ามีทางปลดล็อก 2 ทาง ไม่ใช่ทางเดียว:**

| # | ทาง | ใคร | เวลา |
|---|---|---|---|
| A | เจ้าของ re-auth `yt_token.json` เพิ่ม scope `youtube.readonly` | เจ้าของ | ~5 นาที · แก้ถาวร อ่านอัตโนมัติได้ตลอดไป |
