## บันทึกเทคนิค
- แท็บอยู่เบื้องหลัง (`visibilityState=hidden`) แต่ **หน้าโพสต์เดี่ยวโหลดได้ปกติ** (innerText 3,547 / 4,774) — อ่านคอมเมนต์ครบโดยไม่ต้องเลื่อนฟีด
- ยืนยันซ้ำ: **ห้ามดึง `a.href` เต็ม** (โดน `[BLOCKED: Cookie/query string data]`)
- เทคนิคตรวจ mod signal ที่ใช้ได้: เปิดโพสต์ที่เราเคยคอมเมนต์ → นับ `เงินเดือนสมองทอง` ในหน้า + grep คำว่า `ละเมิด|ถูกลบ|เตือน|ระงับ` แล้ว**ดู context ก่อนสรุป** (วันนี้ hit 2 อัน เป็น false positive ทั้งคู่: ตัวนับแจ้งเตือน + คำว่า "กับดักที่อยากเตือน" ในคอมเมนต์ของเราเอง)
