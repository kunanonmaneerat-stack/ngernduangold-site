## 🎯 หลักฐานที่เปลี่ยนเกณฑ์เลือกกระทู้ (แก้ 21 ก.ค. 2026)
GA4 พิสูจน์: **18 ก.ค. ตอบกระทู้คนดูเยอะ → คนใหม่เข้าเว็บ 11 คน · 20 ก.ค. ตอบกระทู้เล็กเพิ่งตั้งคนดูน้อย → 0 คน**
→ ตัวแปรชี้ขาดไม่ใช่ "สดที่สุด/ตรงหัวข้อสุด" แต่คือ **"คำตอบเราถูกคนเห็นกี่คน"** · เลือกกระทู้ต้องดู engagement (คนดู/คอมเมนต์) เป็นหลัก

STEPS:
1. เปิด https://pantip.com/forum/sinthorn ผ่าน claude-in-chrome — **ต้องให้แท็บ visibilityState=visible ก่อน** (ถ้าอยู่เบื้องหลัง: สร้างแท็บใหม่/Ctrl+9 ให้เป็น active · ดู OPERATING-NOTES ข้อ tab-visibility) ไม่งั้นฟีดโหลดไม่ครบ · Chrome/login ใช้ไม่ได้ = แจ้งสั้นแล้วหยุด ห้ามกรอกรหัส
   → อ่านฟีด "กระทู้ล่าสุด" + กระทู้ active ในห้อง · **เก็บจำนวนคนดู + จำนวนคอมเมนต์** ของทุกกระทู้ที่ตรงหัวข้อ (Pantip โชว์ไอคอนคนดู 👁 และคอมเมนต์ 💬 ในแต่ละแถว)
2. **เกณฑ์เลือก (engagement-first):** คัดกระทู้ที่ผ่านครบ a–d ก่อน แล้ว **จัดอันดับด้วย "คนเห็นเยอะสุด"**
   - (a) อายุ ≤3 วัน (ไม่ต้องสดที่สุด ขอแค่ยังไม่ตกหน้า)
   - (b) ตรงหัวข้อเรา (หนี้/บูโร/อายัดเงินเดือน/ทวงหนี้/รวมหนี้/คลินิกแก้หนี้/จำนำทะเบียน/รีไฟแนนซ์รถ)
   - (c) จขกท.ขอความช่วยเหลือจริง
   - (d) **ยังไม่มีคำตอบที่ครอบคำถามหลักของ จขกท.** — กระทู้ที่มีคอมเมนต์เยอะแต่เป็นมิจ/ตอบสั้น/ไม่ตรงจุด = ยังมีช่องให้เราเพิ่มค่า (แบบนี้ดีสุด: คนเห็นเยอะ + เรายังมีของให้)
   → **ในบรรดาที่ผ่าน a–d เลือกตัวที่คนดู/คอมเมนต์มากสุด** · กระทู้เล็กคนดูหลักสิบแม้ตรงหัวข้อ = deprioritize (ตอบไปคนไม่เห็น = บทเรียน 20 ก.ค.) · หลักคร่าว: คนดูหลักร้อยขึ้น ดีกว่ากระทู้เพิ่งตั้งคนดูหลักสิบ
   → ถ้ามีแต่กระทู้คนดูน้อยทั้งหมด = รายงานว่า "วันนี้ไม่มีกระทู้ reach คุ้ม ขอข้ามรอบ" (ไม่ต้องฝืนใช้โควตากับกระทู้ที่คนไม่เห็น — โควตา 3/สัปดาห์มีค่า)
3. อ่าน OP + คอมเมนต์ทั้งหมด → เขียนคำตอบไทย value-first เจาะเคสนั้นจริง: แม่นยำ ให้กำลังใจ ไร้ลิงก์/แบรนด์/เลขดอกเบี้ย/การันตี + เตือนมิจฉาชีพเมื่อเข้าเรื่อง ("โอนก่อนได้เงิน/ไม่เช็กบูโร = มิจ") · ปรับจากคลังร่าง _pantip_referral_*.md ได้แต่ห้ามวางแบบ generic
4. **CTA หลังไมค์ (บังคับทุกร่าง):** จบร่างด้วยประโยคแนว "ถ้าอยากได้รายละเอียดเฉพาะเคส ทักหลังไมค์มาคุยได้ครับ ยินดีช่วยฟรี" (ไร้ลิงก์/แบรนด์ = ถูกกติกา) — เป้าหมาย: แปลง trust เป็นการคุยหลังไมค์ → ค่อยส่งลิงก์เมื่อเขาทักมา
5. **เช็กหลังไมค์+คอมเมนต์เก่า:** เปิดข้อความหลังไมค์ของบัญชี (ไอคอนซองจดหมาย) — มีคนทักไหม + คห.ที่เราเคยตอบมีคนตอบกลับ/ถามต่อไหม → รายงานจำนวน (metric: ≥3 เคส/สัปดาห์ = เฟสนี้เวิร์ก) · มีคนถามต่อ = ร่างคำตอบต่อให้เจ้าของเคาะด้วย
6. ส่งมอบ: URL + หัวข้อ + **จำนวนคนดู/คอมเมนต์ (reach ที่คาดว่าคำตอบจะถูกเห็น)** + เหตุผล 1 บรรทัด (ทำไมกระทู้นี้: intent สูง + คนเห็นเยอะ + เรายังมีของให้) + ร่างพร้อมวาง + ยอดหลังไมค์ → เจ้าของเคาะในแชต แล้ว Cowork จะ assisted-post ให้ (หรือเจ้าของโพสต์มือ) · โพสต์แล้วต้อง append ledger (channel=pantip, ใส่ field views ด้วยถ้าเก็บได้)
7. ไม่มีกระทู้ผ่านเกณฑ์ (หรือมีแต่คนดูน้อย) = บอกสั้นๆ แล้วหยุด ห้ามฝืนร่างคุณภาพต่ำ/กระทู้ reach ต่ำ
