## เคส A — บัตรใบเดียว ~8,000 "จ่ายเพิ่มจากขั้นต่ำช่วยไหม?"
(พบจริง: หนี้ 8,000 จ่ายขั้นต่ำ ~300 เพิ่มเป็น ~1,300/เดือน)
```
ช่วยได้เยอะเลยครับ ลองดูตัวเลข: บัตรเครดิตดอกเพดาน ธปท. 16%/ปี ≈ 1.33%/เดือน
หนี้ 8,000 → ดอกเดือนแรก ~106 บาท
• จ่ายขั้นต่ำ ~300: ตัดต้นแค่ ~194/เดือน → ลากยาว 2 ปีกว่า ดอกรวมหลายพัน
• จ่าย 1,300: ตัดต้น ~1,194/เดือน → ปิดได้ใน ~7 เดือน ดอกรวมแค่หลักร้อย
ยิ่งจ่ายเกินขั้นต่ำเยอะ ยิ่งประหยัดดอก+ปิดไว — เคสคุณคุ้มมากที่จ่าย 1,300
(ลองกดเครื่องคำนวณดูของตัวเองได้ เสิร์ช ngernduangold มีแจกฟรี)
ข้อมูลเพื่อการศึกษา ไม่ใช่คำแนะนำเฉพาะบุคคลนะครับ
```

## เคส B — KTC Proud/สินเชื่อบุคคล ~39,600 @ 2,500/เดือน
```
สินเชื่อบุคคล (เช่น KTC Proud) ดอกสูงกว่าบัตร — เพดาน ธปท. 25%/ปี ≈ 2.08%/เดือน
หนี้ 39,600 → ดอกเดือนแรก ~825 บาท
• จ่าย 2,500: ตัดต้น ~1,675 → ปิดใน ~28 เดือน
• เพิ่มเป็น 3,500: ตัดต้น ~2,675 → ปิดใน ~17 เดือน (ประหยัดดอกรวมหลายพัน)
ถ้ามีหลายก้อน: โปะแบบ Avalanche (ทุ่มก้อนดอกสูงสุดก่อน ที่เหลือจ่ายขั้นต่ำ) คุ้มดอกสุด
(เครื่องคำนวณช่วยดูเดือนปิดหนี้ให้ชัด เสิร์ช ngernduangold ฟรี)
ข้อมูลเพื่อการศึกษา ไม่ใช่คำแนะนำเฉพาะบุคคลครับ
```

## เคส C — หลายใบ ดอกสูง "จ่ายขั้นต่ำรวมแล้วยอดไม่ขยับ"
(พบจริง: 3 ใบ ดอกรวม 16–25% จ่ายขั้นต่ำรวม ~2,000)
```
เข้าใจเลยครับ จ่ายขั้นต่ำหลายใบพร้อมกัน ดอกกินเกือบหมด ต้นเลยแทบไม่ลด
2 ทางที่ช่วยได้จริง:
1) Avalanche — ทุ่มใบ "ดอกแพงสุด" ก่อน (ที่เหลือจ่ายขั้นต่ำ) → ประหยัดดอกรวมสุด
2) รวมหนี้/รีไฟแนนซ์ — ถ้าย้ายไปก้อนเดียวดอกต่ำลงได้ จะเหลือเงินไปโปะต้นมากขึ้น
   (เทียบจุดคุ้ม+ค่าธรรมเนียมก่อนเสมอ)
กดเครื่องคำนวณใส่ทุกใบ จะเห็นเลยควรโปะใบไหนก่อน + อีกกี่เดือนหมด (เสิร์ช ngernduangold ฟรี)
ข้อมูลเพื่อการศึกษา ไม่ใช่คำแนะนำเฉพาะบุคคล · เรื่องรวมหนี้มีลิงก์พันธมิตรในเว็บครับ
```
