## 1 · `buy_intent_click` ยิงจริงไหม — พิสูจน์แล้ว 3 ชั้น แต่มี 1 ข้อที่พิสูจน์จากเครื่องนี้ไม่ได้

**ชั้นที่ 1 — listener + payload (ผ่าน)**
กดทั้ง 3 ปุ่มบน production ผ่านเบราว์เซอร์ โดย stub `gtag` ไว้ก่อน (ไม่ปนสถิติจริง) ได้ครบ 3/3:
```
{"event","buy_intent_click",{product:"letter-kit-199", position:"mid",     page:"/debt-letter-kit"}}
{"event","buy_intent_click",{product:"letter-kit-199", position:"mid-ask", page:"/debt-letter-kit"}}
{"event","buy_intent_click",{product:"letter-kit-199", position:"end",     page:"/debt-letter-kit"}}
```
`gtagWasReal: true` — แปลว่าบนหน้าจริงมี gtag ของจริงอยู่ ไม่ใช่ตัวปลอมที่ผมใส่

**ชั้นที่ 2 — เข้า dataLayer จริง (ผ่าน)**
ยิงจริงโดยไม่ stub แล้วอ่าน `dataLayer` เห็น event พร้อม payload ครบ · `google_tag_manager` global มีอยู่ · `gtag/js?id=G-17PPE0M1B8` โหลดสำเร็จ

**ชั้นที่ 3 — ส่งถึงเซิร์ฟเวอร์ GA4 (พิสูจน์จากเบราว์เซอร์นี้ไม่ได้ — และผมไม่อยากให้เข้าใจผิดว่าผ่าน)**
ดัก `sendBeacon` / `fetch` / `Image.src` ทุกช่องทางที่ GA4 ใช้ส่งข้อมูล ผลคือ **ไม่มีการส่งออกเลยแม้แต่ `page_view` ตอนโหลดหน้า** (`outboundAll: 0`)
นั่นคือลักษณะของเบราว์เซอร์ในสภาพแวดล้อมทดสอบที่ไม่ส่ง analytics ออก **ไม่ใช่อาการของ event ที่เขียนผิด** — ถ้า event เราพัง `dataLayer` จะไม่มีอะไรเลย แต่มันมีครบ

**หลักฐานทางอ้อมที่ปิดช่องว่างนี้ได้พอสมควร:** `affiliate_click` ใช้กลไกเดียวกันเป๊ะ (เรียก `gtag('event', ...)` จาก inline listener บนหน้าเดียวกันของเว็บนี้) และมีข้อมูลใน GA4 **9 ครั้งใน 28 วัน** → เส้นทาง gtag → GA4 ของเว็บนี้ทำงานกับผู้ใช้จริง
สิ่งที่ต่างกันคือใครเรียก `gtag` ซึ่งชั้นที่ 1–2 พิสูจน์แล้วว่าฝั่ง `buy_intent_click` เรียกถูกต้อง

> **สิ่งที่เจ้าของยืนยันได้ใน 1 นาที (ผมทำแทนไม่ได้เพราะต้อง login):** เปิด GA4 → Realtime → กดปุ่มบน `/debt-letter-kit` จากมือถือ/เบราว์เซอร์ปกติ → ควรเห็น `buy_intent_click` ภายใน ~30 วินาที
> ถ้าไม่ขึ้น ให้บอกผม จะได้ไม่รอเก้อจนถึง 8 ส.ค.

⚠️ **เรื่องที่ต้องรู้ก่อนถึง 8 ส.ค.:** GA4 รับ custom event อัตโนมัติ (นับ event ได้เลย) แต่ **พารามิเตอร์ `position` / `product` จะไม่ขึ้นในรายงานจนกว่าจะลงทะเบียนเป็น custom dimension ใน GA4 UI**
ถ้าอยากได้ breakdown ว่าปุ่มบนหรือปุ่มล่างที่คนกด ต้องลงทะเบียน 2 ตัวนี้ (Admin → Custom definitions) — ถ้าไม่ทำ เราจะเห็นแค่ยอดรวม ซึ่งยัง**ตัดสินตามตารางใน order ได้ครบ** เพราะตารางใช้แค่ 0 / >0
