- **รายงานมีสองบรรทัดที่ห้ามสลับกัน:**
  ```
  ## ตัวเลขสองบรรทัดที่ห้ามสลับกัน
  - affiliate_click (คลิก ≠ เงิน) : N — จะเป็นเงินต่อเมื่อ AccessTrade อนุมัติ conversion
  - ยอดขายจริง (sales-log.jsonl)  : N ชิ้น · N บาท
  ```
- **VERDICT ใหม่ 3 ทาง** (เดิมประกาศ PROVEN จากคลิกอย่างเดียว):
  | เงื่อนไข | verdict |
  |---|---|
  | มียอดขายจริง | `PROVEN: มีรายได้จริงแล้ว — reach คือคอขวดถัดไป` |
  | มีคลิก/quiz แต่ยอด 0 | `UNPROVEN: มีคนสนใจ แต่ยังไม่มีหลักฐานว่าปลายทางรับเงินได้` + สั่งให้ยืนยันปลายทางก่อนเติม reach |
  | ไม่มีทั้งคู่ | `REFUTED: ปัญหาอยู่ที่ funnel` |

  ด้วยข้อมูลปัจจุบัน (คลิก 9 · ยอด 0) รายงานรอบหน้าจะขึ้น **UNPROVEN** ไม่ใช่ PROVEN
