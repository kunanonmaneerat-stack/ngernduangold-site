# REACH CHANNEL UNLOCK — FB open groups (10 ก.ค. 2026, Cowork ลงมือจริง)

## Ground truth ที่เจอจากการลงมือ
- กลุ่มหนี้เดิม 2 กลุ่มของเจ้าของ (ปรึกษาหนี้บัตรเครดิตและสินเชื่อ / สิทธิประโยชน์บัตรเครดิต) = **ปิดคอมเมนต์ทุกโพสต์ + ไม่มีช่องให้สมาชิกโพสต์** → ใช้ทำ reach ไม่ได้ (เป็นบอร์ดแอดมินคุม)

## แก้: หา + เข้าร่วมกลุ่ม "เปิด" (สมาชิกโพสต์ได้จริง) — เข้าร่วมแล้ว 3 กลุ่ม (~45k reach)
1. **ปิดหนี้ บัตรเครดิต นอกระบบ รวมหนี้ บ้านเงินเหลือ คอนโดเงินเหลือ** — 1.8 หมื่น · 60+ โพสต์/วัน · facebook.com/groups/worldprothailand ✅ joined
2. **ปิดหนี้ มีอยากมีบ้าน บูโร ซื้อบ้านไม่ได้ รวมหนี้ แก้ปัญหาติดแบล็คลิส** — 1.5 หมื่น · 90+ โพสต์/วัน ✅ joined
3. **แก้ปัญหาหนี้บัตรเครดิตสินเชื่อส่วนบุคคลบัตรเงินสดและหมายศาล By Admin แมน** — 1.2 หมื่น · 20+ โพสต์/วัน ✅ joined
- ทั้งหมด public · สมาชิกโพสต์ได้ · แต่ broker/นอกระบบเยอะ → **โพสต์ value ล้วน สร้าง trust** · first-post อาจถูก admin review

## งานต่อ (fb-daily-draft engine + owner) — ตาม REACH-CONTENT-STANDARD
- โพสต์ value 1 กลุ่ม/วัน หมุนเวียน 3 กลุ่ม (ไม่ยิงพร้อมกัน = กันสแปม) · วัด GA4 fb sessions/conv
- ยังไม่ได้โพสต์วันนี้เพราะหน้า FB group ค้าง (frozen) → โพสต์รอบถัดไป
