## 🔴 งาน 1 (P0) · `ngernduangold-clicktest` ยิง `affiliate_click` จริงเข้าสถิติ

งานนี้ (Playwright · อาทิตย์ ~10:07) **กด affiliate link จริงเพื่อทดสอบว่า event ยิงออกและ sub_id ถูก** — ซึ่งเป็นงานที่ดีและเคยจับ attribution leak ได้จริง (`2f1e064`)
แต่ผลข้างเคียงคือ **ทุกครั้งที่รัน มันเพิ่ม `affiliate_click` เข้า GA4 property เดียวกับของจริง**

28 วันมี `affiliate_click` = 9 · clicktest รัน 3 ครั้ง/30 วัน → **มากถึง 1 ใน 3 ของเมตริกเงินอาจเป็นของเราเอง**
และ `affiliate_click` คือตัวที่ `check_sales_recorded` กับ verdict ใช้ตัดสิน **เรากำลังตัดสินใจธุรกิจด้วยคลิกของหุ่นยนต์ตัวเอง**

**เลือกหนึ่งวิธี เรียงตามที่ผมแนะนำ:**
1. **ส่ง traffic_type=internal** — ตั้ง GA4 debug/internal parameter ใน Playwright context (เช่น query `?ga_internal=1` + config ให้ GA4 filter) แล้วยืนยันว่า event ไม่เข้ารายงานหลัก · **ดีที่สุด: ยังทดสอบได้จริงและไม่ปน**
2. **แยก GA4 property สำหรับเทส** — สะอาดที่สุดแต่ต้องตั้งค่าเพิ่ม
3. **ถ้าทั้งสองทำไม่ได้** — บันทึกจำนวนคลิกที่ clicktest ยิงลง `automation-log/` ทุกครั้ง แล้วให้ `ga4_pull` **ลบออกจากตัวเลขที่รายงาน** พร้อมเขียนกำกับว่าหักไปเท่าไร

**ห้ามแก้ด้วยการเลิกกดลิงก์** — งานนี้มีคุณค่าจริง (จับ leak มาแล้ว) การปิดคือเสียเครื่องมือ

**เกณฑ์ผ่าน:** รันงานนี้ 1 ครั้ง แล้วพิสูจน์ด้วยตัวเลขว่า `affiliate_click` ในรายงานหลัก **ไม่เพิ่ม**
